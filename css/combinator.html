CSS Combinators Example

1. Descendant Combinator (space)

This paragraph becomes Blue.

This paragraph also becomes Blue.

2. Child Combinator (>)

This paragraph becomes Red.

This paragraph is NOT selected.

3. Adjacent Sibling (+)

Heading

This paragraph becomes Green.

This paragraph stays normal.

4. General Sibling (~)

Heading

This paragraph becomes Purple.

This paragraph also becomes Purple.

Some other element

This paragraph also becomes Purple.
